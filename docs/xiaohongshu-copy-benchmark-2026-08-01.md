1. 选取观夏官方小红书账号近期同一主题的 4 篇笔记作为参考样本。
2. 每篇保存完整笔记，并标注一个能代表写作判断的片段及理由。
3. 将《方寸展桌，裸的变奏》作为盲测目标。生成前只看标题和账号主页封面，不读取正文。
4. 根据标题、封面和参考样本中已经公开的系列背景整理写作需求。
5. 通过 Lumos AI Writer 网页生成文案。
6. 生成完成后才读取目标笔记原文，从信息准确性、结构、语言、情绪和品牌辨识度五个维度对比。

## 样本共性

- 先写物、地点或动作，品牌判断通常后置。
- 事实层与感受层交替推进：历史、地理、材质、成分之后才出现比喻或情绪。
- 比喻有可观察的形态依据，如棉花之于云、瓷器曲线之于远山与静卧的人。
- 句子并非一味短促；长句承担事实，短句承担转场或收束。
- 常用「我们想」「这一次」「如今」等轻微的叙述主体，不高声说服读者。
- 结尾回到“本真、柔软、安顿”等品牌母题，但不追加购买号召。
- 标题常采用“具体物象 + 逗号/竖线 + 状态或动作”，留有解释空间。

### 归因拆分

- 上游需求推断错误：仅凭封面把桌上陈列理解成香氛洗护产品，并加入“从香气走向肌肤照料”；这不是目标原文的方向。
- Skill 生成错误：即使沿用错误需求，也不应逐句搬运四篇参考，更不应为了满足固定段落偏好重复同一品牌母题。
- 不可由盲测得知的信息：目标原文的“五年前”时间点不在四篇参考的明确事实中，不将缺失这一点单独算作模型编造或遗漏。

### 本轮落地修改

- Analysis Skill 从 `1.0.x` 升至 `1.1.2`：要求先选一条事实主线，引用只用于追溯，执行建议不得提供改写后的参考成句，并禁止把未知关键词解释成现场物件。
- Draft Skill 升至 `1.3.1`：短稿允许并优先 2 段；参考全文只进入分析阶段，草稿阶段只接收用户偏好、避坑点、标签概览和当前 brief。
- 增加两级参考复用门禁：参考正文连续重合 16 字及以上时拒绝；人工标注中的完整短分句被照搬时也拒绝。
- 修复共享 Schema 与短稿策略冲突：`aiDraftCopySchema` 最少段落数从 3 改为 2。
- 修复器接收明确的 `bannedVerbatimPhrases`，短重合位于结尾时允许整句重写，不再强行保留候选收束。
- 新增可重复执行的真实品牌评测脚本：`server/api/scripts/benchmark-guanxia.ts`。
