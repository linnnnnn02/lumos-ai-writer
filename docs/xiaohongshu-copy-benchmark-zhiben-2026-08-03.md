# 小红书品牌文案盲测：至本

评测日期：2026-08-03

## 评测目标

至本代表的特殊问题是：护肤产品说明如何同时做到极短、可信、有品牌克制感，又不写成参数表，不把科学或产品名称扩写成营销保证。

- 品牌账号：至本（小红书号 27762684113）
- 账号主页：<https://www.xiaohongshu.com/user/profile/5c4bc681000000001003d41d>
- 盲测目标：《炎燥季节，时时特安》
- 目标来源：<https://www.xiaohongshu.com/explore/6a57225a0000000021020e9c>

生成前只读取目标标题和封面，不读取正文。封面展示两件标签不可读的护肤产品，位于带水滴的模糊玻璃后。

## 同模式参考

### 自然，净澈

> 30℃自然结晶，泡沫细腻绵柔；既是清洁过程，亦是温和享受。

标注理由：先给具体工艺事实，再落到触感；“温和”有事实支点。

### 润而不腻

> 轻盈，顺滑，四季皆宜。

标注理由：三个短判断分别回答负担、触感和季节范围，不追加夸张结果。

### 夏天的15分钟

> 一种夏天也合适的乳霜质地；多重修护油脂封闭渗透，避免「过度水合」。敏弱肌可享的安稳修护体验。

标注理由：先回应季节顾虑，再解释机制；机制直接服务使用判断。

### 轻盈，唤醒

> 紧致淡纹，修护提亮；多维焕活肌肤光采。

标注理由：用分号把多个功效压成“具体改善方向—整体状态”，只学习压缩方式，不迁移功效事实。

## 跨模式干扰参考

跨模式组加入三篇同账号真实文案：活动掉落通知《限时掉落 | 舒颜卸妆膏好礼派送》，以及空瓶回收叙事《1个收纳筐≈4.3支空瓶》《瓶生迎来重大转折》。它们分别会向目标施加活动流程、数字价值和拟人陪伴三种干扰。

Analysis 将活动稿判为 `campaign_interaction`，两篇回收稿判为 `brand_story`，目标仍为 `product_education`；最终兼容参考数为 0。活动步骤、环保数据与拟人关系均未进入目标稿。

## 目标原文

> 给肌肤「1+1>2」的密集关照。

标签为 `#特安双子星`、`#特安修护密集面膜`、`#特安修护密集精华液`。正文只有约 15 字，主要任务不是展开产品事实，而是压缩两件产品的组合关系与一个护理判断。

## 初始失败

无参考盲测在事实不足时出现“皮肤需要细致的关怀”“营造出宁静的氛围”等空泛填充，并在修复后仍失败。

同模式盲测没有迁移参考功效，但生成了“天气越来越热”“桌上放着”“静静待在玻璃后”等未支持场景。说明参考机制在缺少产品事实时，会诱使模型拿视觉氛围代替事实骨架。

揭晓完整事实后的第一版虽然事实较完整，但正文达到 90 字左右，并补出“面膜先行，精华跟进”“带来更深层舒缓”。“配合使用”被错误扩写成使用顺序和额外功效。

## 落地修改

- Draft Skill 升至 `xiaohongshu-draft@1.8.6`。
- 新增 `ultra_short` 长度契约：brief 明确要求极短、单句或一行配文时，正文允许 12–72 字，优先一段，不再沿用普通短稿的 40 字下限和两段偏好。
- 新增 `sparse_short` 长度契约：必写事实不超过两条时允许 12–96 字，优先一段，给事实审计留下“删除后直接停止”的空间。
- `required=true` 改为语义覆盖要求，不要求每条事实单独成句、解释或逐项展开；主体、组合关系与一个判断可以压进同一句。
- 产品名中的“修护、净澈、舒缓”等功效词只属于名称，不能作为新增效果证据。
- “配合使用”不蕴含先后顺序、协同机制、双倍效果、程度提升或具体功效。
- 事实审计新增产品组合与视觉边界用例，明确拦截“面膜先行，精华跟进”“更深层舒缓”“静待探索”“功效未知”等扩写。
- 缺少产品信息时，不把构图、遮挡、标签可读性、静止状态或资料缺口写成正文；可选视觉事实不推进必写主线时应删除。
- Analysis Skill 升至 `reference-analysis@1.3.2`。账号级稳定语气必须至少在两篇参考、两种不同内容模式中重复出现；单篇里的“你”、短句、拟人或互动方式不能直接升为账号偏好。
- `benchmark-zhiben.ts` 新增 `none|cross|same` 三种参考组、盲测/知情开关和 1–10 次连续运行统计。

## 三层经验

### 账号专属证据

至本在本组产品说明中偏好短句、理性、少互动，以可核验事实支撑触感或判断。这些证据只进入至本账号或项目写作档案，不能据此要求其他品牌也使用同样语气。

### 内容模式经验

极短产品说明可以只保留“组合主体 + 组合关系 + 一个护理判断”。工艺、成分和机制只有在当前 brief 明确提供时才展开；产品教育参考中的具体功效不能迁移到另一产品。

### 跨账号通用能力

1. 明确的极短意图必须改变输出长度契约，不能只把普通短稿写得稍短。
2. 必写事实覆盖不等于逐项展开；能合并表达时应在事实说完后停止。
3. 视觉事实不能替代产品事实，资料缺口也不能变成“功效未知、等待揭晓”等读者侧文案。
4. 名称里的功效词和产品间的组合关系都不能作为机制、顺序或效果的推导依据。

## 剩余风险

信息缺失组仍只有 3/5 通过，其中两稿虽然没有编造功效，却让可选视觉构图占据正文。继续增加提示词的收益已经有限；更合理的产品方案是让 Draft API 在关键产品事实不足时返回结构化 `insufficient_facts` 状态，提示用户补充产品名、关系或可核验判断，而不是继续尝试生成成稿。
